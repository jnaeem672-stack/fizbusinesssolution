# University logo assets — draft for review

Prepared 30 October 2026. All 44 existing university entries have a local image. Existing university names, student-count claim, and affiliation disclaimer are preserved; those claims were not substantiated by this logo change.

## Publication status

**Draft only. No trademark licence or permission has been established. Downloading an image does not grant publication rights, and the existing non-affiliation disclaimer is not a licence.** Verify required permissions and brand clear-space/minimum-size rules before merging or deploying. Official homepage artwork was used where obtainable; the source exceptions below need confirmation/replacement before release.

- Oxford: external use requires a University licence: https://www.ox.ac.uk/about/the-university/brand/protecting-the-university-logo
- Imperial: external organisations are directed to contact the style guide team: https://www.imperial.ac.uk/communications/contacts/ . Official template repository restricts logos/fonts to staff and students for university business: https://github.com/ImperialCollegeLondon/imperial_latex_templates
- Prince Sultan: visual identity use outside official frameworks requires approval: https://psu.edu.sa/en/ICM0007-visual-identity-policy
- UCL logo guidance: https://www.ucl.ac.uk/brand-and-experience/brand/visual-guidelines/logo/logo-guidelines
- KFUPM guidance: https://mediacenter.kfupm.edu.sa/brand-guidelines/
- KAUST guidance: https://ipomedia.kaust.edu.sa/toolkit/KAUST/KAUST_Brand_Style_Guide.pdf
- KSU guidance: https://identity.ksu.edu.sa/en/node/143

Remaining institutions: no external-use licence established; individual permission and current brand requirements remain unverified.

## Sources

Raster images are proportionally resized and stored as lossless WebP; artwork colours and geometry remain intact. Excess blank canvas on the IAU and PSU reference copies is removed while retaining a 10px border; no artwork is cropped. SVGs retain original paths; the KFUPM XML encoding declaration was corrected to match UTF-8 bytes. White artwork uses a dark display panel. No hotlinks or generated/recreated logos.
